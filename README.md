# 🚗 Car Sales Analytics Project

## 📌 Project Overview

This project focuses on analyzing car sales data using Python, SQL, and Power BI to identify sales trends, evaluate company performance, and generate meaningful business insights.

The project follows an end-to-end data analytics workflow, including Exploratory Data Analysis (EDA), data cleaning, SQL-based business analysis, and interactive dashboard development using Power BI.

## 🎯 Project Objectives

* Analyze overall car sales performance.
* Identify year-wise and quarterly sales trends.
* Compare sales performance across car companies.
* Analyze sales by dealer region, body style, and customer gender.
* Calculate total sales, total cars sold, and average car price.
* Generate business insights to support data-driven decision-making.
